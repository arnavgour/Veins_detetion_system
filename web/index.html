      About

      How Vena reads a hand.

      Vena is a demonstration studio for dorsal hand-vein analysis — not a clinical or identity product. Click any stage in the explorer to see why it exists, how the code implements it, the exact parameters, and what the frame should look like. The same guide appears as Why / How / Parameters tabs in Studio while an image is processing.

      What it is for Teaching the computer-vision steps behind vein biometrics using the same functions as preprocess.py and features.py.
      How to use this page Filter by group, click a stage, then Next / Previous. From Studio, “Open this step in About” lands on the matching card.
      Endpoint — one skeleton neighbor Bifurcation — three or more neighbors

      How to run

      From the project root, with the virtualenv that already has OpenCV and FastAPI:

      .venv/bin/python app.py

      Then open http://127.0.0.1:8000. The repository README has the same process write-up in long form.
